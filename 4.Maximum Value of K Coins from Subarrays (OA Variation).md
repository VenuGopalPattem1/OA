# Maximum Value of K Coins from Subarrays (OA Variation)

## Problem Description
You are given a 2D integer array `pilesGrid` of size `n x m` representing `n` rows of coins, where unused or empty positions are padded with `-1`. 

For each row, valid coins appear continuously from the start until the first occurrence of `-1` (or the end of the row).

You need to select a total of at most `k` coins across all rows subject to the following condition:
* If you pick $L$ coins from row $i$, you must pick them as a single **contiguous subarray** of length $L$ from the valid elements in that row.
* You can pick at most one contiguous subarray from each row (or pick 0 coins from that row).

Return the **maximum total sum** of coins you can collect.

## Example Walkthrough

### Example 1
```text
Input:
pilesGrid = [
    [1, 100, -1],
    [7, 2, -1]
]
k = 2

Output: 107
```

**Explanation:**
* Row 0 valid elements: `[1, 100]`
  * Subarrays of length 1: `[1]` (sum 1), `[100]` (sum 100) -> Best = 100
  * Subarrays of length 2: `[1, 100]` (sum 101) -> Best = 101
* Row 1 valid elements: `[7, 2]`
  * Subarrays of length 1: `[7]` (sum 7), `[2]` (sum 2) -> Best = 7
  * Subarrays of length 2: `[7, 2]` (sum 9) -> Best = 9

**Optimal Pick:**
* Take 1 coin from Row 0: `[100]` (Value: 100)
* Take 1 coin from Row 1: `[7]` (Value: 7)
* Total coins = $1 + 1 = 2 \le k$
* Total sum = $100 + 7 = 107$.

## Approach

The solution breaks down into two distinct phases:

### Phase 1: Precompute Maximum Subarray Sum by Length
For each row $i$:
1. Count the number of valid coins $m$ (stop at `-1`).
2. Construct an array `best[i]` where `best[i][L]` stores the maximum sum of any contiguous subarray of length $L$ in row $i$.
3. Compute this using standard sliding window or nested loops across all valid `start` and `end` indices.

### Phase 2: Dynamic Programming (0/1 Group Knapsack)
Let `dp(i, rem_k)` represent the maximum value obtainable using rows from index `i` to `n - 1` with a remaining coin budget of `rem_k`.

* **State Transition:**
  $$\text{dp}(i, \text{rem\_k}) = \max_{0 \le L \le \min(m, \text{rem\_k})} \Big( \text{best}[i][L] + \text{dp}(i + 1, \text{rem\_k} - L) \Big)$$
* **Base Case:** 
  $$\text{If } i == n \text{ or } \text{rem\_k} == 0 \implies 0$$

## Java Implementation

```java
import java.util.Arrays;

public class Solution {
    private static int n;
    private static Integer[][] dp;
    private static int[][] best;

    public static int maxValueOfKCoins(int[][] pilesGrid, int k) {
        n = pilesGrid.length;
        dp = new Integer[n][k + 1];
        best = new int[n][];

        // Step 1: Precalculate best contiguous subarray sums for every row
        for (int i = 0; i < n; i++) {
            // Count valid coins (stop at -1)
            int m = 0;
            while (m < pilesGrid[i].length && pilesGrid[i][m] != -1) {
                m++;
            }

            best[i] = new int[m + 1];
            for (int start = 0; start < m; start++) {
                int sum = 0;
                for (int end = start; end < m; end++) {
                    sum += pilesGrid[i][end];
                    int len = end - start + 1;
                    best[i][len] = Math.max(best[i][len], sum);
                }
            }
        }

        // Step 2: Solve with Top-Down DP
        return fun(0, k);
    }

    private static int fun(int i, int k) {
        // Base Case: no more piles left or no coins left to pick
        if (i == n || k == 0) return 0;

        // Memoization lookup
        if (dp[i][k] != null) return dp[i][k];

        int max = 0;
        // Try taking 'len' coins from row i (0 <= len <= min(pileLength, k))
        for (int len = 0; len < best[i].length && len <= k; len++) {
            int current = best[i][len] + fun(i + 1, k - len);
            max = Math.max(max, current);
        }

        return dp[i][k] = max;
    }
}
```

## Complexity Analysis

| Metric | Complexity | Explanation |
| :--- | :--- | :--- |
| **Precomputation Time** | $\mathcal{O}\left(\sum m_i^2\right)$ | Enumerating all contiguous subarrays per row of length $m_i$. |
| **DP Time** | $\mathcal{O}(n \cdot k \cdot \min(m, k))$ | There are $n \times k$ states, each doing a loop up to $\min(m_i, k)$. |
| **Space Complexity** | $\mathcal{O}(n \cdot k + \sum m_i)$ | DP memoization matrix + precomputed `best` arrays. |
