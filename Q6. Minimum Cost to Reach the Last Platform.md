# Q6. Minimum Cost to Reach the Last Platform

## Problem Description

You are given `N` platforms.

Each platform has a cost/value.

You start at platform `0` and need to reach the **last platform**.

From every platform, you can:

- Make a **single jump** to the next platform: `i -> i + 1`
- Make a **double jump** to the next-next platform: `i -> i + 2`

But there is one restriction:

> You cannot make two consecutive double jumps.

Your goal is to find the **minimum total cost** required to reach the last platform.

The cost is paid when you land on a platform.

---

## Test Case 1

### Input

```text
cost = [10, 15, 20, 5]
```

One possible path:

```text
0 -> 1 -> 3
```

Cost:

```text
15 + 5 = 20
```

Another path:

```text
0 -> 2 -> 3
```

Cost:

```text
20 + 5 = 25
```

Therefore:

```text
Output = 20
```

## Test Case 2

### Input

```text

```

Possible path:

```text

```

Jumps:

```text
double -> single -> single
```

Cost:

```text
10 + 1 + 20 = 31
```

Another possible path:

```text
0 -> 2 -> 4
```

Jumps:

```text
double -> double
```

This is not allowed because two consecutive double jumps are forbidden.


## Memoization Approach

We need two pieces of information to define our DP state:

```text
i
prevDouble
```

Where:

```text
i = current platform

prevDouble = 0
means previous jump was NOT a double jump

prevDouble = 1
means previous jump WAS a double jump
```

So our DP state is:

```text
dp[i][prevDouble]
```

It represents:

> Minimum cost required to reach the last platform starting from platform `i`, knowing whether the previous jump was a double jump.

### Single Jump

We can always make a single jump:

```text
i -> i + 1
```

After a single jump, the previous jump is no longer double.

So:

```text
cost[i + 1] + fun(i + 1, 0)
```

### Double Jump

A double jump is:

```text
i -> i + 2
```

But it is allowed only when the previous jump was not double.

Therefore:

```text
if (prevDouble == 0)
```

we can make:

```text
cost[i + 2] + fun(i + 2, 1)
```

After making a double jump:

```text
prevDouble = 1
```

### Recurrence

```text
fun(i, prevDouble) = minimum of:

1. cost[i + 1] + fun(i + 1, 0)

2. cost[i + 2] + fun(i + 2, 1)
   only when prevDouble == 0
```

---

## Base Case

When we reach the last platform:

```text
i == n - 1
```

we do not need to pay anything more.

Therefore:

```text
return 0;
```

---

## Final Memoization Solution

```java
class Solution {
    Integer[][] dp;
    int[] cost;
    int n;

    public int minCost(int[] cost) {
        this.cost = cost;
        this.n = cost.length;

        dp = new Integer[n][2];

        return fun(0, 0);
    }

    public int fun(int i, int prevDouble) {

        // Reached the last platform
        if (i == n - 1) {
            return 0;
        }

        // Already calculated
        if (dp[i][prevDouble] != null) {
            return dp[i][prevDouble];
        }

        int ans = Integer.MAX_VALUE / 2;

        // Single jump: i -> i + 1
        if (i + 1 < n) {
            ans = Math.min(
                ans,
                cost[i + 1] + fun(i + 1, 0)
            );
        }

        // Double jump: i -> i + 2
        // Allowed only if previous jump was NOT double
        if (prevDouble == 0 && i + 2 < n) {
            ans = Math.min(
                ans,
                cost[i + 2] + fun(i + 2, 1)
            );
        }

        return dp[i][prevDouble] = ans;
    }
}
```

## Dry Run for Test Case 1

```text
cost = [10, 15, 20, 5]
```

Start:

```text
fun(0, 0)
```

We are at platform `0` and the previous jump was not double.

We have two choices.

### Choice 1: Single Jump

```text
0 -> 1
```

Cost of platform `1`:

```text
15
```

Then:

```text
fun(1, 0)
```

From platform `1`:

```text
1 -> 2
```

or:

```text
1 -> 3
```

The better path is:

```text
0 -> 1 -> 3
```

Cost:

```text
15 + 5 = 20
```

### Choice 2: Double Jump

```text
0 -> 2
```

Cost:

```text
20
```

Now:

```text
fun(2, 1)
```

The previous jump was double, so another double jump is not allowed.

Only:

```text
2 -> 3
```

is possible.

Cost:

```text
20 + 5 = 25
```

Therefore:

```text
min(20, 25) = 20
```

```text
20
```

## Complexity

There are:

```text
N × 2
```

possible DP states.

Each state does only constant work.

Therefore:

```text
Time Complexity = O(N)
```

The memoization table contains `N × 2` states:

```text
Space Complexity = O(N)
```

---

## Key Idea

The important thing is that `i` alone is not enough.

For example:

```text
fun(i, 0)
```

and:

```text
fun(i, 1)
```

are different states.

Why?

Because if:

```text
prevDouble = 0
```

we are allowed to make a double jump.

But if:

```text
prevDouble = 1
```

we cannot make another double jump.

So the state is:

```text
fun(currentPlatform, previousJumpWasDouble)
```

This is the main idea behind the memoization solution.
